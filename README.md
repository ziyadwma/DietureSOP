# Dieture SOP Management System

A comprehensive Standard Operating Procedures (SOP) management system for Dieture, allowing for the creation, review, approval, and management of SOPs across departments.

## Features

- User authentication with role-based access control
- SOP creation, editing, and version control
- Department management
- User management
- Approval workflows
- Responsive design for desktop and mobile

## Tech Stack

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- shadcn/ui components
- Client-side data persistence with localStorage (can be replaced with a real backend)
